ÇEKİRDEK • core.logic.GameLogic

Oyunun kalbi

  • int[6][7] tahta — taş atınca yerçekimiyle en alta düşer.
  • checkWin() — atılan taştan 4 yöne (yatay/dikey/2 çapraz) bakar.
  • Kazanan 4 hücreyi saklar → arayüzde parıldatmak için.
  • Kopya kurucu — AI'nin geleceği simüle etmesi için tahtayı klonlar.
  • Beraberlik, sıra yönetimi ve reset tek yerde.
// Sadece son taşın etrafına bakar — O(1) gibi hızlı
int row = dropDisc(col);   // taşı bırak
if (checkWin(row, col))    // 4'lü dizi var mı?
    gameOver = true;
else if (isBoardFull())     // tahta doldu mu?
    gameOver = true;     // → beraberlik
else
    currentPlayer = diğer;  // sıra rakibe

AĞ OYUNU • core.network

İki bilgisayar, tek tahta

  • Sunucu (Host) oyunun tek doğru kopyasını tutar — hakem odur.
  • İstemci (Client) yalnızca aynalar; hamleyi gönderir, sonucu çizer.
  • Her ikisi de NetworkPeer arayüzünü uygular → GameScreen ikisini de aynı şekilde kullanır.
  • Port 5555 üzerinden satır-tabanlı TCP metin protokolü.
  • Hile imkânsız: geçerlilik kontrolü hep sunucuda.
